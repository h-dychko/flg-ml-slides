AdamW — Decoupled Weight Decay

The fix: decouple weight decay from gradients

Adam
g̃t = gt + λ θt  // L2 added to gradient → gets scaled by adaptive rate
AdamW
θt+1 = θt − η · m̂t / (√v̂t + ε) − η λ θt  // weight decay applied directly
mt, vt, m̂t, v̂t  — same as Adam
θt+1 = (1 − η λ) θt − η · m̂t / (√v̂t + ε)  // λ = weight decay

Why it matters

Problem with Adam + L2
✗L2 penalty is added to the gradient, then divided by v̂t — the adaptive rate weakens regularization for frequently updated params
✗Weight decay strength varies per parameter — harder to tune λ
AdamW fix
✓Weight decay is applied uniformly, independent of the gradient magnitude
✓Better generalization — especially for Transformers & large models
✓Default optimizer in Hugging Face, PyTorch Lightning, and most LLM training
Adam + L2 ≠ weight decay — they only coincide for SGD. AdamW decouples them, making regularization predictable and effective across all parameters.
