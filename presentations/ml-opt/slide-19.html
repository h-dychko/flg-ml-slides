17 · Vanishing & Exploding Gradients

Backprop multiplies many values — that can go wrong

The chain rule stacks multiplications

∂L/∂W1 = ∂L/∂an · ∂an/∂an−1 · … · ∂a2/∂a1 · ∂a1/∂W1
values < 1 → product shrinks → vanishing
values > 1 → product grows → exploding
🫥 Vanishing gradients
Cause
  • Mult. by small values (< 1)
  • Sigmoid / tanh saturation
Symptoms
  • Loss decreases very slowly
  • Early layers don't learn
Fix
  • ReLU / GELU activations
  • Residual connections
  • Proper initialization
💥 Exploding gradients
Cause
  • Mult. by large values (> 1)
  • Deep nets, large weights
Symptoms
  • Loss → huge / NaN
  • Unstable training
Fix
  • Gradient clipping
  • Lower learning rate
  • Better initialization
