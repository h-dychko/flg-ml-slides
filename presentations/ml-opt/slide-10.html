Adam — Adaptive Moment Estimation

Algorithm

Momentum
+
RMSProp
= Adam
mt = β1 mt−1 + (1−β1) gt  // 1st moment (mean)
vt = β2 vt−1 + (1−β2) gt2  // 2nd moment (variance)
m̂t = mt / (1 − β1t)  // bias correction
v̂t = vt / (1 − β2t)  // bias correction
θt+1 = θt − η · m̂t / (√v̂t + ε)  // parameter update

Pros & cons

Pros
✓Fast convergence with minimal tuning
✓Handles sparse and noisy gradients well
✓Bias correction stabilizes early training
Cons
✗Can generalize worse than SGD+momentum on some tasks
✗More memory: stores mt and vt per parameter
Adam gets you moving fast; SGD + momentum can sometimes win on final test performance — both are worth knowing.
