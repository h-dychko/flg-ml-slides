16 · Debugging Training

Optimization debugging checklist

Symptom
Likely cause & first action
Loss does not decrease
LR too low, broken gradients, bad preprocessing, or implementation bug
Loss explodes or becomes NaN
LR too high, exploding gradients — add gradient clipping or reduce LR
Training loss is very noisy
Batch size too small, LR too high, missing normalization
Train loss drops, test loss does not
Overfitting — increase regularization, reduce model capacity, or add more data
Very slow progress
LR too low, poor initialization, or wrong optimizer defaults
