20 · Practical Takeaways

Practical defaults for training neural networks

Learning rate is the highest-leverage knob
Adam + 3×10−4 is a strong starting point
SGD + momentum often wins on final accuracy
Cosine annealing is a safe default schedule
Add warmup for transformers and large batches
Monitor train and validation loss together
Optimization speed ≠ generalization quality

Default workflow for a new task

  1. Start with Adam, lr = 3×10−4, warmup + cosine schedule
  2. Confirm loss is decreasing and training is stable
  3. Tune the learning rate before anything else
  4. Switch to SGD + momentum once stable if generalization matters
  5. Add warmup if using large batches or a transformer architecture

When the defaults stop working

  • Loss is NaN or explodes — LR too high, or exploding gradients; clip or reduce LR
  • Training is stuck or very slow — LR too low, bad initialization, or vanishing gradients
  • Train loss drops, val loss doesn't — overfitting; add regularization or reduce capacity
  • Adam converges fast but SGD beats it on test — sharp vs flat minima; try SGD with a schedule
