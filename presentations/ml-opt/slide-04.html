3 · Gradient Descent

Batch Gradient Descent

Algorithm

Compute the gradient across the entire dataset, then take a single parameter update.

g = ∇θ L(θ)   // full dataset
θ ← θ − η g

Pros & cons

Pros
✓Stable, low-variance gradient estimate
✓Well-studied convergence properties
Cons
✗Extremely expensive on large datasets
✗One update per full pass — very slow
✗Impractical for modern deep learning
