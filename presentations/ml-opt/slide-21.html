17 · Second-Order Methods

Beyond gradients: Newton's method & L-BFGS

Core idea

Second-order methods use curvature information (the Hessian ∇2L) in addition to gradients, allowing more informed step directions and sizes.

First-order uses ∇L only
Second-order uses ∇L + ∇2L

Why not the default in deep learning?

  • Computing the full Hessian is O(n2) — prohibitive for millions of parameters
  • L-BFGS approximates it, but still costly in memory and compute
  • Minibatch noise makes curvature estimates unreliable
  • First-order methods scale much better to modern network sizes
Second-order methods can be powerful for smaller models and full-batch settings — they see use in scientific computing and classic ML — but first-order methods dominate deep learning.
